PROJECT LONG MEMORY

项目介绍

解决什么问题做了什么如何判断是否有用当前状态

AI 项目通常需要经历许多次对话。Project Long Memory 关注这些对话之间的连续性：哪些决定仍然有效，哪些事情还没做完，新的任务需要知道哪些背景。

解决什么问题

新对话缺少前情，容易重复解释、重复尝试。把历史全部带回来又会引入过时决定和无关信息。项目记忆需要兼顾连续性与选择性。

做了什么

按项目保存重要决定、未完成事项和相关来源，在后续工作开始时检索有关内容。记录有误或条件发生变化时，需要能够更正，并让新的决定被找到。

如何判断是否有用

重点检查是否引用了错误项目、是否继续采用已经废弃的决定，以及实际工作是否减少了重复交代。程序测试用于核对范围和流程，日常使用用于检验取回的内容是否合适。

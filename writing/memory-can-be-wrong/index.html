项目记忆，需要保留更正的能力

保存历史之外，还要识别哪些决定已经不再适用。

李少钦 / CHOQIN2026.09 · AI 协助整理

长期项目需要记住已经做过的工作。但保存下来的内容并不总是正确，也不总是适用于现在。

一个决定通常依赖当时的条件。需求、技术和使用方式变化以后，如果系统仍然把旧决定作为当前要求，记忆就会影响后续工作。

Project Long Memory 因此需要记录来源、项目归属和更正信息。检索结果不只要与当前问题相关，还要能够判断它是否已经被后来的决定取代。

评价记忆工具，不能只看找回了多少内容。更实际的问题是：新对话能否继续工作，是否少解释了一次，是否避免重复走过已经放弃的路径。
